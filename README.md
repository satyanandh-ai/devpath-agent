## 🎯 What is DevPath?

Most career tools answer: *"Here are some tips."*

**DevPath answers: "Here is your exact gap, why it matters, and what to do about it — based on your GitHub, resume, and real 2026 hiring data."**

DevPath is an end-to-end **AI Career Intelligence Platform** that:

- 🔬 **Verifies** your resume claims against your GitHub evidence
- 📊 **Scores** your profile using 5 computed engines (not LLM guesses)
- 🏢 **Benchmarks** you against real 2026 job market data
- 🤖 **Retrieves** from a curated knowledge base before every answer (RAG)
- 👔 **Simulates** a recruiter's 30-second candidate decision
- 🎤 **Prepares** you for interviews with role-specific questions + AI scoring

### 📄 Resume Intelligence + Real ATS Engine
> **No LLM guessing. 5 computed categories.**

| Category | Max | What it checks |
|---|---|---|
| Contact Info | 20 | Email, Phone, LinkedIn, GitHub |
| Resume Sections | 20 | Summary, Education, Skills, Projects, Experience |
| Skills Coverage | 20 | Tiered scoring: 0-3 skills=5pts, 16+=20pts |
| Keywords & Verbs | 20 | Action verbs + quantified achievements |
| Formatting & Length | 20 | Word count curve, bullets, dates, section headers |
| **Max Score** | **99** | *A perfect resume is never auto-given* |

✅ Extracts all technical skills via LLM  
✅ Suggests top 5 job roles  
✅ Gives 5 specific improvement actions

### 🐙 GitHub Intelligence
> **Portfolio Score from real repo signals — not an LLM opinion.**

Scores every repository across 5 dimensions:

```
Deployment      → Does it have a live demo link?
Documentation   → Does it have a description?
Originality     → Is it a fork or original work?
Consistency     → Was it updated in the last 6 months?
Code Quality    → Does it have stars?
```

Output: **Portfolio Score /100** + Radar Chart + Top Repos ranked by signal strength

### 🌉 Reality Check — The Killer Feature
> *"Most ATS tools can't do this. Most career tools can't do this."*

**Resume ↔ GitHub Credibility Engine:**

```
Resume Claims:          GitHub Evidence:        Status:
─────────────────       ─────────────────       ────────
Python              →   5 Projects Found    →   ✓ Verified
FastAPI             →   2 APIs Found        →   ✓ Verified
```

## 📦 Installation

```bash
# 1. Clone the repository
git clone https://github.com/satyanandh-ai/devpath-agent.git
cd devpath-agent

# 2. Create virtual environment
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Set up environment variables
cp .env.example .env
# Add your keys to .env:
# GROQ_API_KEY=your_groq_key_here
# GITHUB_TOKEN=your_github_token_here

# 5. Run the app
streamlit run app.py
```
